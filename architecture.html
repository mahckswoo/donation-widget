What changed from the previous diagram

  • was  fetch / XHR donation APIs · needs CORS headers now  <iframe> document load · gated by frame-ancestors CSP — the browser makes no donation API call at all; CORS is irrelevant.
  • was  GET embed.js + SVG now  GET embed.js — one self-contained file; the mascot is Lottie JSON inlined, no separate SVG.
  • was  (not shown) now  webhook giving.sg → partner server on completion, and postMessage "cancel" iframe → widget to close. Both were missing.
Secrets note: OAuth client-credentials + x-api-key belong only to the separate redirect / sessionurl flow, where the partner’s backend calls the API. In this iframe flow there are no secrets and no partner backend — giving.sg’s per-origin frame-ancestors allowlist does the trust job a key otherwise would.
